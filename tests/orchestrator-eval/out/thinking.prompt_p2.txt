We are given a Phase 2 specification for a "Complaints Board" in a FastAPI application.
 The task is to produce a delegation packet for a fresh implementer (subagent) that has no prior context.

 Steps from the spec:
 1. Create `models.py` with a `Complaint` dataclass and a module-level list `complaints`.
 2. Populate `complaints` with 3-5 seed complaints.
 3. Add a `GET /complaints` route in `app.py` that returns `templates/complaints.html` with the complaints list.
 4. Create `templates/complaints.html` that extends `base.html` and displays the complaints as Bootstrap cards.
 5. Write tests in `tests/test_app.py` for the new route.

 Existing files after Phase 1:
   - `app.py`
   - `templates/base.html`
   - `templates/home.html`
   - `tests/test_app.py`

 We are to produce a packet that tells the implementer what to do, without writing code.

 Requirements for the packet:
   - Name each repo-relative writable file and mark it NEW or SHARED.
   - For SHARED files, list every route, import, test, string, and user-visible behavior that MUST survive.
   - State exact literals that must appear verbatim.
   - Give the single validation command.
   - State any framework semantic trap the implementer must know.
